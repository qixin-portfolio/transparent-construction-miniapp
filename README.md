# 晟景透明工地小程序开发骨架

这是从交接文档继续推进出来的微信小程序骨架，放在当前工作区，便于继续开发和导入微信开发者工具。

## 当前版本包含

- 工作台、工地列表、新增工地、工地详情、上传日报、审核日报、客户库、新建客户、业主进度、我的 10 个页面。
- 微信云开发云函数：登录、客户、工地、日报上传、审核、业主进度、业主绑定码、企业微信通知、每日闭环。
- 已接入真实 AppID、云环境，并完成云函数部署。
- 已创建业务数据库集合和常用查询索引。
- 已验证企业微信机器人提醒可用。
- 已补上扫码/分享直达时的自动登录，业主不需要先绕到“我的”页面。
- 业主进度页已升级为轻量 v2：顶部进度、现场照片、施工时间线。
- 已补齐交接文档里最关键的几个坑：
  - 审核通过后同步更新 `photos.ownerVisible`。
  - 业主端把云存储 `fileID` 转成临时图片 URL。
  - 提交日报成功后尝试发送企业微信群提醒。
  - 待审核列表补齐真实项目名。
  - 云函数增加基础角色和项目可见性校验。
  - 补了内部新增工地入口，方便试运行时造测试工地。
  - 前端 demo 数据改成显式 `DEMO_MODE` 开关，默认关闭。

## 导入方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本目录：`透明工地小程序/开发骨架`。
4. 当前项目已配置真实小程序 AppID。
5. 当前项目已配置真实微信云开发环境 ID。
6. 云开发已创建集合：
   - `users`
   - `customers`
   - `projects`
   - `project_members`
   - `stage_logs`
- `photos`
- `tasks`
- `owner_bind_codes`
   - `notifications`
7. `cloudfunctions` 下所有云函数已部署。
8. 企业微信提醒已通过云函数环境变量接入。

不要把真实 AppID、环境 ID、Webhook、Token 或密码写入公开文档或前端代码。

## 角色说明

- `admin`：管理员，可管理全部数据。
- `boss_qi`：老齐，可看全部工地并审核日报。
- `boss_hu`：老板娘，可看全部工地并审核日报。
- `designer`：设计师，可看和自己相关的客户、工地。
- `worker`：工长/师傅，可提交自己负责工地的日报。
- `owner`：业主，只能看绑定到自己微信的工地进度。

新用户登录后默认是 `owner`。内部员工角色需要在云数据库 `users` 集合中由管理员手动改角色，第一版先不做后台角色管理页。

## 当前限制

- 业主绑定码已完成，仍需要准备真实业主账号做一次端到端验证。
- 第一版没有做在线支付、合同、主材商城、供应商结算。
- 员工角色暂时需要在云数据库 `users` 集合中设置，尚未做小程序内角色管理页。
- 客户和工地当前以新增、查看为主，编辑、删除、跟进记录还未做完整。
