# 微信审核提审备注

本版本已整改首次进入强制授权问题。

未登录或尚未绑定项目的用户打开小程序后，不会自动请求手机号、微信头像或昵称，也不会自动进入工作人员注册页面。

用户可以直接点击“体验示例工地”，无需任何个人信息授权即可浏览项目概览、施工进度、施工日报、现场照片、设计确认和问题验收等核心功能。

已由晟景装饰开通项目权限的业主，会根据现有微信身份直接进入所属工地。尚未绑定项目的用户将看到明确提示，可联系项目负责人开通，不会被强制授权或注册。

微信头像和昵称不作为登录或使用核心功能的前置条件。

## 7.3.4 AI 日报整改备注

本版本已按审核意见整改。AI日报生成页面已在生成结果区域显著标明“AI生成内容”和“本页文字由人工智能生成，请人工核验并修改后提交”，生成结果以“AI生成草稿”展示，所有内容均须由工作人员人工核验、编辑并提交审核。
