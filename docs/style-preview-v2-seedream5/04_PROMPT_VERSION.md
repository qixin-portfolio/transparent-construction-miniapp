# Prompt Version

Version: `style-preview-v1-seedream5-structure-first`.

The prompt treats the source bare-room image as the sole authority for camera, perspective, walls, doors, windows, beams, columns, openings, dimensions, and fixed structure. The reference image controls style only. A customer note requesting structural changes is explicitly ignored while lawful style and furnishing preferences remain usable.

The output target is one realistic, buildable-feeling Chinese residential interior image with no diagram, dimensions, text, brand logo, third-party watermark, or conceptual replacement space.
