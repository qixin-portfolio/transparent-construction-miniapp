# V2 Deal Loop Phase 5C-A：真实证据摘要产品文案与风险提示设计

## 当前阶段

Phase 5C-A：真实证据摘要产品文案与风险提示设计。

本阶段只设计 `trust-materials` 页面中“真实证据摘要 / 示例推荐素材 / 公开授权提示”的产品文案与风险提示。不修改业务代码，不部署，不上传体验版，不打开工作台入口，不进入 Phase 5C-B。

## 设计目标

1. 让老板和销售能一眼理解：真实证据摘要是内部成交跟进参考，不是可直接发布的宣传素材。
2. 明确区分三类内容：
   - 真实客户字段
   - 真实证据摘要
   - 示例推荐素材
3. 对公开授权状态做更谨慎的解释，避免出现“可直接发小红书 / 抖音 / 官网 / GEO”的误导。
4. 错误态文案不暴露内部错误码，不提 `tenantId`，不提 `customerId`，不让用户误以为数据丢失。
5. 为 Phase 5C-B 的最小页面文案实现提供边界，不扩大到云函数、入口、tabBar 或其它页面。

## 真实证据摘要文案设计

### 标题

推荐：

```text
真实证据摘要
```

备选：

```text
工地证据摘要
```

说明：

- “真实”用于和下方“示例推荐素材”区分。
- “摘要”强调只看统计和状态，不看原始照片、日报正文和文件。

### 副标题

推荐：

```text
仅统计已审核、业主可见的工地记录，不展示原始照片和日报正文。
```

备选：

```text
用于内部成交跟进参考，已做脱敏处理。
```

说明：

- 当前页面用户是老板/销售，副标题要直接说明“能看什么”和“不能看什么”。
- 不建议继续只写“已脱敏”，因为销售可能不清楚脱敏意味着什么。

### 只读标签

推荐：

```text
只读摘要
```

备选：

```text
内部参考
```

说明：

- “只读摘要”保留技术边界。
- “内部参考”可配合授权标签使用，降低业务误解。

### 数据来源说明

有真实摘要时：

```text
真实客户字段 + 真实证据摘要 + 示例推荐素材
```

有真实客户但无真实摘要时：

```text
真实客户字段 + 示例推荐素材
```

缺少客户入口或读取客户失败时：

```text
示例客户字段 + 示例推荐素材
```

说明：

- 将 `Mock` 面向用户替换为更自然的“示例”。
- 如果仍需给开发者看，可在调试文档保留 `Mock`，页面上优先使用“示例”。

### 无证据状态文案

推荐：

```text
暂无可用证据摘要，可继续查看示例推荐素材。
```

辅助说明：

```text
当前客户暂未匹配到已审核、业主可见的工地记录；这不代表客户资料丢失。
```

说明：

- 不把 `NO_EVIDENCE` 说成系统错误。
- 不提示 fallback 到其它客户。
- 明确“不代表资料丢失”，避免老板误解为数据异常。

### 读取失败文案

推荐：

```text
证据摘要暂时读取失败，请稍后重试。
```

辅助说明：

```text
当前仍可查看示例推荐素材，但不要把示例素材当作该客户的真实证据。
```

说明：

- “暂时”降低误解，但不掩盖失败。
- 必须明确示例素材不能冒充真实证据。

### 未找到文案

推荐：

```text
未找到可用工地证据，请返回客户列表重新打开。
```

辅助说明：

```text
为避免串用客户资料，本页不会自动切换到其它客户。
```

说明：

- 不提内部 ID。
- 不提示“这个客户不存在”或“这个工地不属于你”，避免 ID 探测和租户信息泄露。

## 公开授权提示文案设计

### 状态 A：可公开使用

标签推荐：

```text
已具备公开使用授权
```

主文案：

```text
该客户证据已具备公开使用授权。发布前仍建议人工复核客户授权范围、素材内容和平台规则。
```

限制说明：

```text
可用于公开案例前，请确认不包含手机号、地址、业主隐私、施工图和未授权照片。
```

说明：

- 不写“可直接发布”。
- 不写“可直接发小红书 / 抖音 / 官网 / GEO”。
- 即使授权通过，也保留人工复核要求。

### 状态 B：暂不可公开发布

标签推荐：

```text
仅内部参考，暂不可公开发布
```

主文案：

```text
这些摘要可用于内部成交跟进参考，但暂不能包装成公开案例或宣传素材。
```

限制说明：

```text
不可直接用于小红书、抖音、官网、GEO 等公开渠道。如需公开使用，请先取得案例授权。
```

说明：

- 直接点名公开渠道，避免销售误解。
- “案例授权”是下一步动作，但不在本阶段实现。

## 示例推荐素材文案设计

当前页面需要继续保留 mock 推荐素材，但建议面向业务用户改成“示例推荐素材”。

### 区域标题

推荐：

```text
示例推荐素材
```

辅助说明：

```text
以下内容仅供话术和跟进思路参考，不代表当前客户的真实工地证据。
```

### 素材来源

推荐：

```text
来源：示例素材
```

备选：

```text
来源：示例库
```

### 操作按钮

当前按钮：

```text
mock 发送给客户
```

推荐改为：

```text
查看示例话术
```

或：

```text
预览示例内容
```

说明：

- 当前按钮只弹窗，不真实发送。
- “发送给客户”容易让销售误以为已经可以实际发送，本阶段建议避免。

### Mock 标注

如果仍需保留 `Mock` 字样，建议放在较低层级：

```text
Mock 推荐素材，仅供内部测试
```

更适合老板/销售的表达：

```text
示例推荐素材，仅供内部参考
```

## 错误态文案设计

页面不展示内部错误码，不提 `tenantId`，不提 `customerId`。

| 状态 | 页面标题/标签 | 推荐文案 | 使用边界 |
| --- | --- | --- | --- |
| `NO_EVIDENCE` | 暂无真实证据摘要 | 暂无可用证据摘要，可继续查看示例推荐素材。 | 不当成系统错误，不 fallback 到其它客户 |
| `NOT_FOUND` | 未找到可用工地证据 | 未找到可用工地证据，请返回客户列表重新打开。 | 不暴露 ID 是否存在，不显示内部原因 |
| `READ_FAILED` | 摘要读取失败 | 证据摘要暂时读取失败，请稍后重试。 | 不冒充真实证据，可显示示例素材但必须标明示例 |
| `FORBIDDEN` | 暂无查看权限 | 当前账号暂无查看证据摘要权限。 | 不展示摘要，不展示内部权限规则 |
| `UNAUTHENTICATED` | 需要先登录 | 请先登录后再查看证据摘要。 | 不展示摘要，不 fallback |
| `NO_MARKETING_AUTHORIZATION` | 仅内部参考，暂不可公开发布 | 可用于内部成交跟进参考，暂不可用于小红书、抖音、官网、GEO 等公开渠道。 | 不是系统错误，不阻断内部摘要阅读 |

### 错误态统一辅助说明

推荐：

```text
为避免串用客户资料，本页不会自动切换到其它客户。
```

适用状态：

- `NOT_FOUND`
- `READ_FAILED`
- `FORBIDDEN`
- `UNAUTHENTICATED`

说明：

- 这句话能解释“为什么不 fallback”，老板/销售更容易理解。
- 不需要出现任何内部技术字段。

## 风险提示设计

### 页面顶部提示

推荐：

```text
V2 试验功能：仅用于内部成交跟进，不影响现有客户、工地和日报数据。
```

备选：

```text
当前为 V2 试验功能，证据摘要只读展示，不会修改客户、工地或日报数据。
```

### 真实证据摘要底部提示

推荐：

```text
本区只展示脱敏摘要，不展示原始照片、文件地址、日报正文和个人隐私。
```

### 示例素材区提示

推荐：

```text
示例素材只用于参考话术，不代表该客户已有对应真实证据。
```

### 公开授权提示

推荐：

```text
未取得案例授权前，不要将内部证据摘要用于公开宣传。
```

说明：

- 顶部提示解决“这是试验功能吗”的问题。
- 摘要区提示解决“这里是不是能看照片”的问题。
- 示例区提示解决“示例是不是客户真实证据”的问题。
- 授权提示解决“能不能直接发公开平台”的问题。

## 风险点

1. “真实证据摘要”容易被误解为“可公开宣传素材”，必须用授权提示区分。
2. “示例推荐素材”容易被误解为当前客户真实证据，必须持续标注示例属性。
3. “可公开使用”也不能写成“可直接发布”，仍需人工复核授权范围。
4. `NO_EVIDENCE` 不能被说成数据丢失，只是暂无可用摘要。
5. `READ_FAILED` 不能 fallback 到其它客户，也不能冒充真实证据。
6. Phase 5C-B 如修改页面文案，必须保持入口关闭，不得顺手打开工作台入口。
7. 当前 `NOT_FOUND / READ_FAILED / FORBIDDEN / UNAUTHENTICATED` 仍未完成实机覆盖，不适合进入发布动作。

## 是否建议进入 Phase 5C-B

2. 不改云函数。
