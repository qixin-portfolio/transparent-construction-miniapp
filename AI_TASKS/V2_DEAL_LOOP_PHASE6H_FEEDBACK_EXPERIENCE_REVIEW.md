1. Phase 6-F：反馈模块体验版短期打开入口

   - 入口仍仅在 `ENABLE_V2_DEAL_LOOP_ENTRY && isBoss` 条件下显示
   - 体验对象限定为 boss_qi
   - 体验窗口限定为 1 天以内

2. 人工上传体验版
   - 人工基于 Phase 6-F 入口打开 commit 上传反馈模块体验版
   - 体验目标是验证反馈模块、复制反馈问题、销售跟进提示、客户成交复盘是否有实际价值

3. Phase 6-G：恢复入口关闭

   - 提交关闭入口 commit/tag
   - 代码层入口默认重新隐藏

4. Phase 6-G2：重新上传关闭入口体验版覆盖上一版

   - 已覆盖上一版入口打开体验版
   - 当前体验版入口已关闭
