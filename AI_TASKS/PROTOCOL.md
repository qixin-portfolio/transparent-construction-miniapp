# ChatGPT + Codex + Reviewer 协作协议（简化版）

## 协作定位

- ChatGPT 负责目标拆解、方案讨论和风险判断。
- Codex 负责代码实现、测试和工程执行。
- Matrix/Reviewer 负责检查实现质量和发现问题。
- 三者可以并行协作，不要求严格串行等待。

## 默认流程

1. 明确目标和验收标准。
2. Codex 修改代码。
3. Reviewer 可随时审查当前代码状态。
4. 根据反馈快速迭代。
5. 需要时提交 commit、PR 或文档记录。

## 保留要求

- 不提交密钥、token、密码。
- 不绕过权限和安全限制。
- 不自动发布生产版本。
- 高风险操作需要用户确认。

## 原则

减少流程成本，把注意力放在产品、代码质量和验证结果上。
