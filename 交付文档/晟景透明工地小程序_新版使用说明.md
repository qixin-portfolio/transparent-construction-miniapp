# 晟景透明工地小程序新版使用说明

日期：2026-06-19  
适用版本：UI 1.1/1.2 校准版

## 一、角色说明

| 角色 | 主要使用内容 |
| --- | --- |
| 老板/管理员 | 查看工地、审核日报、客户库、团队管理、AI 助理 |
| 设计师 | 创建/查看工地、上传图纸、客户跟进、AI 助理 |
| 销售 | 客户库、预约线索、签单建工地、AI 助理 |
| 工长 | 查看工地、上传施工日报、查看施工图 |
| 业主 | 绑定工地、查看已审核施工进度、现场照片和设计图 |

## 二、内部员工使用流程

### 1. 员工激活

适用对象：工长、设计师、销售等内部员工。

流程：

1. 管理员进入“我的 -> 团队管理”
2. 选择员工角色
3. 生成 6 位邀请码
4. 发给对应员工
5. 员工进入首页，输入邀请码激活
6. 激活后进入对应角色工作台

注意：

- 邀请码有效期为 7 天
- 同一角色有效邀请码未过期时会复用
- 不同角色要生成不同邀请码

### 2. 创建工地

适用对象：老板、管理员、设计师、销售。

流程：

1. 进入“首页 -> 新增工地”或“工地 -> 新增”
2. 填写工地名称、客户姓名、小区/地址等信息
3. 保存后进入工地详情
4. 后续可上传日报、生成业主绑定码、管理图纸

建议：

- 新签约客户应先从客户详情进入“签单建工地”
- 工地名称建议包含小区、面积或客户简称，便于后续查找

### 3. 上传施工日报

适用对象：工长、设计师、管理员。

流程：

1. 进入工地详情
2. 选择“写施工日报”
3. 选择当前工序
4. 填写今日完成内容、现场问题、需确认事项、明日计划
5. 上传现场照片
6. 提交给管理员审核

注意：

- 日报提交后不是马上给业主看
- 管理员审核通过后，业主端才会展示
- 现场问题和需确认事项要写清楚，方便留痕

### 4. 审核日报

适用对象：老板、管理员。

流程：

1. 进入“我的 -> 审核日报”或首页待办
2. 查看待审核日报
3. 核对工序、文字、照片和问题说明
4. 选择“通过”或“退回”
5. 通过后自动进入业主可见进度

建议：

- 照片不清楚、问题描述含糊时应退回补充
- 审核通过前先确认内容是否适合业主查看

## 三、业主使用流程

### 1. 绑定工地

流程：

1. 业主进入小程序
2. 打开“我的施工进度”或首页绑定入口
3. 输入晟景提供的 6 位绑定码
4. 绑定成功后查看专属工地进度

绑定码来源：

- 内部人员进入工地详情
- 生成业主绑定码
- 复制文案或分享给业主

### 2. 查看施工进度

业主可以看到：

- 当前施工进度百分比
- 当前工序节点
- 已审核日报
- 现场照片
- 设计方案/效果图

业主看不到：

- 未审核日报
- 内部施工图中设置为不可见的内容
- 内部客户管理资料

## 四、客户转化使用流程

### 1. 门店展示与预约

适用对象：潜在客户/业主。

流程：

1. 进入“工地”Tab 的门店展示页
2. 查看晟景介绍、门店信息、完工案例
3. 提交预约量房设计
4. 预约信息进入客户库

### 2. 客户库跟进

适用对象：销售、设计师、老板。

流程：

1. 进入“客户库”
2. 根据阶段筛选客户
3. 查看客户来源、需求和下一步动作
4. 进入客户详情补充电话、地址、需求、预算、风格等信息
5. 推进客户阶段：咨询、已到店、已量房、已出图、已报价、准备签单、已签单

### 3. 签单建工地

流程：

1. 进入客户详情
2. 将客户阶段推进到“已签单”或成交状态改为“已成交”
3. 点击“签单建工地”
4. 新增工地页会自动带入客户姓名和地址
5. 保存后进入施工透明闭环

## 五、设计图纸使用流程

适用对象：设计师、管理员、工长、业主。

### 1. 上传图纸

流程：

1. 进入工地详情
2. 选择“图纸管理”
3. 上传效果图或施工图
4. 选择空间分类
5. 填写标题和备注
6. 设置是否业主可见

### 2. 图纸状态

| 状态 | 含义 |
| --- | --- |
| 业主可见 | 业主端可以看到该效果图 |
| 仅内部可见 | 只给内部人员查看 |
| 待业主确认 | 效果图已展示但业主尚未确认 |
| 施工交底 | 施工图用于内部施工沟通 |
| 待工长查看 | 施工图还未被工长标记已读 |

## 六、AI 助理使用流程

适用对象：老板、设计师、销售。

AI 助理目前包含：

- 客户需求整理
- 报价话术和利润风险
- 施工交底表
- 工地巡检清单
- 透明工地日报
- 案例内容生成
- 三套风格方向

基础流程：

1. 进入“我的 -> 晟景AI助理”
2. 选择工具类型
3. 填写客户、报价、工地或案例资料
4. 生成内容
5. 复制、保存或同步到客户库

推荐用法：

- 销售接待后，用“客户需求整理”沉淀客户信息
- 报价前，用“报价话术和利润风险”准备沟通话术
- 开工前，用“施工交底表”整理客户要求和施工注意事项
- 发朋友圈/短视频前，用“案例内容生成”整理文案

## 七、上线前建议测试清单

### 施工透明闭环

1. 内部账号创建工地
2. 工长上传日报和现场照片
3. 管理员审核通过
4. 生成业主绑定码
5. 业主绑定后查看进度

### 客户转化闭环

1. 门店页提交预约
2. 客户库出现预约线索
3. 客户详情推进阶段
4. 已签单后创建工地

### 内部效率闭环

1. 上传效果图并设置业主可见
2. 上传施工图并标记已读
3. AI 助理生成内容并保存
4. AI 助理客户需求同步客户库
5. 生成员工邀请码并完成激活
